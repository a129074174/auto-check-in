# 笑脸报到

通过摄像头实时采集学生人脸，与学籍系统导出的「相片底册」自动比对，判断签到是否成功，语音播报结果，并导出 Excel。

## 功能

- **底册建库**：扫描「学校/年级/班级」三级目录（文件名 = 身份证号+姓名），自动提取人脸特征并缓存。
- **选班签到**：界面选「学校 → 年级 → 班级」，班级选「全部班级」= 整个年级签到（如填志愿签到）。
- **分级匹配**：班级签到先在该班找、找不到回退整个年级；年级签到直接全年级找；找不到判「匹配失败」。
- **语音播报**：签到成功用 Windows 本地语音播报「XX签到成功」（离线可用）。
- **去重**：同一学生短时间内重复出现只记一次。
- **结果导出**：每次生成 Excel（含班级/姓名/时间/结果），成功/失败/重复分色显示。

## 两种使用方式

### 方式一：打包版（推荐，免装 Python）

1. 运行 `打包程序.bat`，或在 `dist\笑脸报到\` 找到已打好的文件夹。
2. 把整个 `笑脸报到` 文件夹拷贝到任意 Windows 电脑。
3. 双击里面的 `笑脸报到.exe`，浏览器自动打开签到界面。
4. 目标电脑无需安装 Python，人脸模型已内置，完全离线可用。

### 方式二：源码运行（开发者）

1. 双击 `安装环境.bat` 安装依赖（首次会联网下载人脸模型约 300MB）。
2. 双击 `启动签到.bat` 启动，浏览器自动打开。

## 底册照片怎么放

```
base_photos/
└── 示例学校/          ← 学校名
    └── 2024级/        ← 年级
        └── (1)班/     ← 班级
            ├── 11010120000101001X张三.jpg   ← 身份证号+姓名
            └── 11010120000101002X李四.jpg
```

支持 jpg / jpeg / png；文件名 = 18 位身份证号 + 姓名。

## 手机当摄像头

1. 手机装「IP Webcam」等 App，与电脑连同一 WiFi，启动后得到地址（如 `http://192.168.x.x:8080`）。
2. 在签到界面点「摄像头设置」，填 `http://192.168.x.x:8080/video`。
3. 留空或填 `0` 则用电脑本地摄像头（含 DroidCam 等虚拟摄像头，可填设备索引如 `1`）。

## 隐私说明

- `base_photos/`（真实底册照片）和 `data/`（签到结果、特征缓存）**已被 `.gitignore` 排除，不会提交到仓库**。
- 代码、文档、示例数据全部使用占位符（「示例学校」「(1)班」「张三」），不含真实学生信息。
- 打包产物同样不含真实底册与结果。
